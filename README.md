# KARIMO Unpacked

Interactive visual explainer of how [KARIMO](https://github.com/opensesh/KARIMO) transforms product requirements into shipped code.

**Live site:** [karimo-overview.vercel.app](https://karimo-overview.vercel.app)

## What is KARIMO?

KARIMO is an autonomous development framework for Claude Code — plan mode on steroids. It delivers product design-driven orchestration with sub-agents and agent teams, taking features from PRD interview through wave-based execution to merged, reviewed code. Phased adoption lets teams start with PRD generation and scale up to fully automated review and merge.

## Running Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech Stack

- **Framework:** Next.js 16+ (App Router)
- **UI:** React 19, Tailwind CSS v4
- **Animation:** Framer Motion, Three.js (React Three Fiber)
- **Language:** TypeScript
- **Deployment:** Vercel
